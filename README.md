# UNIP - Universal IP Tool

A powerful command-line tool for IP tracking, port scanning, network analysis, and SSH control.

## Features

- IP Tracking to real geographic location
- Port scanning (common ports and ranges)
- DNS and WHOIS lookup
- Ping and traceroute
- SSH control for servers and phones
- Hash generator (MD5, SHA1, SHA256, SHA512)
- Color output interface

## Installation


sudo wget -O /usr/local/bin/unip https://raw.githubusercontent.com/CSG-c/unip/main/unip
sudo chmod +x /usr/local/bin/unip
unip -h
